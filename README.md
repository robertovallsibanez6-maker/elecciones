# Elecciones 29N

Guía de las elecciones generales del 29 de noviembre de 2026: partidos y propuestas, encuestas con hemiciclo, calculadora de pactos, posturas por temas y cómo votar.

Web app instalable: ábrela en el móvil y usa «Añadir a pantalla de inicio».

- `data.js`: todos los datos (partidos, encuestas, temas). Para actualizar, edita este archivo y sube `VERSION` en `sw.js`.
- `app.js`: lógica e interfaz.
- `index.html`: estructura y estilos.

Tipografías: Anybody y Public Sans (SIL Open Font License), alojadas en `fonts/`.
